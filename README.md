# Hide and Seek

**双引擎立体声效果器 · Chicken Chukka**

一段吉他可以先被升高四度，再拖进磁带回声。也可以让两个效果各听同一句演奏，一边留下清楚的重复，另一边慢慢化成混响。Hide and Seek 把这两种接法都放进了同一个面板。

*An unofficial macOS audio effect by Chicken Chukka, based on the Chase Bliss Lost + Found pedal. Two effect slots, twelve algorithms, and three ways to route them.*

**[下载 Mac 版 0.1.78](https://github.com/Huangjunhaoo/hide-and-seek/releases/download/v0.1.78/Hide-and-Seek-0.1.78-Mac.zip)**　·　[发行说明](https://github.com/Huangjunhaoo/hide-and-seek/releases/tag/v0.1.78)　·　[原机对照与测量](#原机对照与测量)

适用 **Apple silicon Mac，macOS 15.6 或更新版本**。ZIP 内含独立程序、AU 插件、安装说明和 MIDI CC / Program Change 指南。

## 先弹一句

想试串联，可以选左槽 **2B Pitch Repeater**、右槽 **4A Tape Echo**，打开两个槽，选 **L → R**。左槽选 **4**，弹几个间隔分明的单音，就能听到移高四度的重复进入磁带回声。再切到 **Parallel**，磁带一侧就会直接收到原来的吉他。单声道输入可打开 **MISO** 获得立体声输出。

左右槽各有一套音色、EQ、IGNORE 和 SYNC。右侧预设栏可收起；点选槽位后按 **Load Selected Slot** 加载，用 **Save to Selected Slot** 把当前声音写入高亮槽。右键点击已有预设可重命名或删除。主面板标题旁显示当前版本号。也可以从 MIDI 控制器发送 **PC 0–127** 直接切换。**PC 0** 是自定义默认音色。

| 1 | Slow-verb | Useful Ambience |

| 3 | Pinging Phaser | Spectral Modulator |

## 原机对照与测量

开发时，先把演奏中听出的差异变成一个可以重测的问题。例如“合唱太厚、转得太快”，可以分别查湿声音量、每个声部延迟了多久，以及它来回摆动一次要多少秒。

| 工作流程 | 实际做法 |
| :-- | :-- |
| 建立参考 | 同一段数字音频一路送进软件，另一路经 MOTU 828 的输出 9/10 送进原机，由输入 9/10 录回立体声。先录干声，量出线路本身的增益和往返延迟，再比较湿声。 |
| 固定条件 | 记录左右槽、旋钮的 MIDI CC 值、Spread、路由、时钟和切换时刻。短脉冲用于找回声和反射的位置，持续单音用于看音高与谐波，不同强度的吉他用于听实际起音和尾音。 |
| 实现算法 | 在 C++ 中实现音频处理，由 JUCE 接入独立版和 AU。可辨认的数字处理路径参考了效果板固件的静态分析，其中 3B、5A、5B、6B 接入了转写代码。Tape 的变速等待、Glue 的动态曲线等行为则用原机回录校准。 |
| 决定是否保留 | 冻结候选参数，用未参与调节的录音复核，再回到吉他试听。修改单个音色时，也重跑已验收的其他音色。混入其他播放、削波或前一次尾音的录音会从拟合中剔除。 |

### 6A Ensemble · 合唱为什么显得太急？

在右槽、MISO 开、Spread 关、Time / Modify / Alt 分别为 **CC 24 / 12 / 64** 的设置下，用一串短脉冲探测延迟。追踪每一组回声相对输入脉冲晚了多少毫秒，再由这些延迟随时间的变化估计声部的摆动周期。

| 同一设置下的声部摆动 | 频率 | 完成一次摆动 |
| :-- | --: | --: |
| Lost + Found 原机 | 0.194 Hz | 约 5.17 秒 |
| 早期软件 0.1.59 | 0.580 Hz | 约 1.73 秒 |
| 修正后 0.1.60 | 0.194 Hz | 约 5.17 秒 |

旧版声部摆了三圈，原机才走完一圈。这给“软件转得快”找到了具体的修改方向。频率对齐以后，还要单独试听湿声音量和声部叠加的厚度。

### 4A Tape Echo · 换速时，音高何时开始弯？

打开 Spread 后，直接改变 Time 和改变 MIDI Clock 的速度，原机有两种不同的等待时间。开发时同时记录命令时刻和音频里的弯音起点，只扣除干声线路延迟。候选参数冻结后，另外补录两条 25 秒的原机参照，每条做三次动作。

| 同一批新录音，比较弯音起点的平均误差 | 调整前 | 调整后 |
| :-- | --: | --: |
| 直接改变 Time | 84.74 ms | 36.98 ms |
| 改变外部时钟速度 | 1443.27 ms | 147.28 ms |

这里量的是测试 MIDI 链路中“发出命令到听见弯音”的时间。演奏输入的音频延迟是另一个量。

### Glue · 为什么还要用吉他复核？

持续单音便于看出压缩量和饱和产生的谐波，却听不出拨弦之后电平恢复得是否自然。Glue 在 **13 个旋钮位置**做了电平测量，另留短音来检查压缩的起落。在一条强饱和吉他素材上，软件与原机的包络平均偏差从 **5.08 dB** 降至 **2.62 dB**。这个数字只描述那条素材、那个设置下的动态差异。

### 1B Useful Ambience · 一次被放弃的修改

为了让同步混响的反射更接近原机，试过调整内部调制的起始相位。在 **6 个参考条件、54 次离线渲染**中，一个候选在 150 BPM 下让频谱误差减少约 **0.62 dB**，却让低 Decay 加 Spread 的条件恶化约 **0.72 dB**。两个设置都有人会用，所以定档版保留了原有处理。

## 定档范围

以上数字来自各音色的开发对照轮次。原机主控版本当时未读出，模拟输入输出级也没有完整建模。长混响的自由相位、演奏电平和调制历史都会影响单次录音，因此这里按具体设置报告结果。0.1.78 的交付检查还覆盖了 AU 验证、预设改名、显式加载、保存到新槽、PC 0 默认槽和宿主工程恢复。
